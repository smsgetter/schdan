# schdan

Agility. is the visual system for schdan: a shadcn-compatible React element library built as **Ark UI foundation → visual pack → motion design → auto-variations**.

The complete implementation is currently in the public [`agility`](https://github.com/smsgetter/agility) repository while this canonical project is being consolidated here.

## Direction

React 19 · Ark UI · Tailwind v4 · Motion · GSAP/Three.js when a scene needs it · Iconify Solar, with Pixelarticons for 8-bit.

Six packs: Liquid, Matte, 8-Bit, Micro Noise, Abstract, Typical. The system exposes 37 elements, five variation axes (`tone`, `border`, `radius`, `size`, `surface`), an iframe demo and a standalone Web Component build.
